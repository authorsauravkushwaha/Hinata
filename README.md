# Hinata

Hinata is a personal desktop assistant built with Python.

## Project Goal

This is a hands-on learning project for understanding:

* Python programming
* Speech recognition
* Text-to-speech
* Command routing
* Windows automation
* Browser automation
* APIs
* Local memory
* Git and GitHub
